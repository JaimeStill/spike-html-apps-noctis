# spike-html-apps-noctis

spike-html-apps-noctis is a color profile for
[spike-html-apps-foundation](https://github.com/JaimeStill/spike-html-apps-foundation), added
from outside the foundation as any extension package would be: Noctis Hibernus in light and Noctis
Obscuro in dark. It is released by tag. This context records only working knowledge the code and
the README do not express.
